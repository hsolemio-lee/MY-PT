The Harness Problem

"대부분의 에이전트 실패는
모델의 문제가 아니라 편집 도구(edit tool)의 문제입니다"

모델 = 누가 일하는가

개발자의 실력 — 어떤 AI를 쓸 것인가

⚙️
하네스 = 어떻게 일하는가

개발 프로세스 — 모델이 어떻게 작동하는가

어떤 모델을 쓸 것인가  <  모델이 어떻게 일하도록 설계할 것인가
